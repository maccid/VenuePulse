# .ia

Carpeta de trabajo personal para la metodología de desarrollo asistido por IA del autor
(especificaciones, seguimiento de tareas, prompts de referencia).

- Vive en la copia local del repositorio, no se entrega como artefacto: nunca puede llegar a
  una imagen Docker (ver `.dockerignore` y el ADR sobre esta garantía).
- El repositorio en sí tampoco se entrega directamente — solo se muestra en pantalla durante
  la entrevista y se distribuye el contenedor Docker ya construido.
- La evidencia curada y pública de cómo se usó la IA en este proyecto vive en
  `docs/AI-USAGE.md`, no aquí.
