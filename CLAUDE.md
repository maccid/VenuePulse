# CLAUDE.md

Este proyecto usa **`AGENTS.md`** como contrato para agentes IA — es la fuente de verdad.

**Antes de tocar nada, lee en este orden:**

1. `.ia/PRODUCT-VISION.md` — qué es VenuePulse, para qué existe y glosario común del dominio.
2. `AGENTS.md` — referencias, modos de trabajo, comandos y flujo git.
3. El resto de `.ia/*.md` según lo que indique la tarea (`ARCHITECTURE.md`, `RULES.md`,
   `GIT-FLOW.md`, `KNOWN-ISSUES.md`, `TODO.md`).

No dupliques criterio ni inventes términos: usa el vocabulario y las decisiones ya fijadas en
esos documentos y en `docs/architecture/adr/`. Si una decisión no está documentada y es
relevante, créala como ADR en vez de improvisarla en el código.

`.ia/`, `AGENTS.md` y este fichero son contexto de trabajo local para acelerar el desarrollo con
IA — no forman parte de lo que se muestra o entrega del proyecto.
